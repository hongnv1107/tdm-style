# tdm-style

A css-in-js solution that combines the [@tdm-design/ui](https://www.npmjs.com/package/@tdm-design/ui) token system with [emotion](https://emotion.sh/).

This is a port of [antd-style](https://github.com/ant-design/antd-style) (MIT, © Arvin Xu) with every token, theme algorithm and component dependency switched from `antd` to `@tdm-design/ui`. The public API is the same as antd-style, so its documentation applies.

## Install

```bash
pnpm add tdm-style @tdm-design/ui@^0.0.32-rc.0
```

Requires `@tdm-design/ui` `>=0.0.32-rc.0`.

## Usage

```tsx
import { Button } from '@tdm-design/ui';
import { createStyles, ThemeProvider } from 'tdm-style';

const useStyles = createStyles(({ token, css, responsive }) => ({
  card: css`
    padding: ${token.paddingLG}px;
    border-radius: ${token.borderRadiusLG}px;
    background: ${token.colorBgContainer};
    color: ${token.colorPrimary};

    ${responsive.mobile} {
      padding: ${token.padding}px;
    }
  `,
}));

const Card = () => {
  const { styles } = useStyles();
  return (
    <div className={styles.card}>
      <Button type="primary">TDM</Button>
    </div>
  );
};

export default () => (
  <ThemeProvider themeMode="auto">
    <Card />
  </ThemeProvider>
);
```

Zero-runtime styles use CSS variables generated by `@tdm-design/ui`:

```ts
import { createStaticStyles } from 'tdm-style';

export const styles = createStaticStyles(({ css, cssVar }) => ({
  title: css`
    color: ${cssVar.colorPrimary}; /* var(--tdm-color-primary) */
  `,
}));
```

## Differences from antd-style

|                                          | antd-style                             | tdm-style                                                                                        |
| ---------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Token source                             | `antd` `theme.useToken()`              | `@tdm-design/ui` `theme.useToken()` (Atlassian Design System based tokens)                       |
| CSS variable prefix (`cssVar`)           | `--ant-*`                              | `--tdm-*`                                                                                        |
| Default emotion key                      | `acss`                                 | `tcss`                                                                                           |
| Breakpoints (`responsive`)               | antd screens                           | tdm screens: xs ≤ 319, sm ≤ 767, md ≤ 1023, lg ≤ 1279, xl ≤ 1919, xxl ≥ 1920, plus `xxxl` ≥ 2560 |
| `extractStaticStyle` component style key | `antd`                                 | `tdm`                                                                                            |
| SSR global                               | `__ANTD_STYLE_CACHE_MANAGER_FOR_SSR__` | `__TDM_STYLE_CACHE_MANAGER_FOR_SSR__`                                                            |

Component class names keep the `ant` / `anticon` prefixes, the same as `@tdm-design/ui`. Only the CSS variable prefix differs: tdm components render `.ant-btn { color: var(--tdm-color-primary) }`.

Hook and type names (`useAntdToken`, `useAntdTheme`, `AntdToken`, …) keep their antd-style names so existing code migrates by changing the import path only.
